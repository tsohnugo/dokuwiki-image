## Repository Introduction

[dokuwiki](https://github.com/dokuwiki/dokuwiki)DokuWiki is an open - source wiki software that is simple and easy to use, versatile, and does not rely on a database. It is loved by users for its concise and readable syntax. What's more, its easy maintenance, convenient backup, and easy integration make it a favorite among administrators. The built - in access control and authentication management make DokuWiki particularly suitable for enterprise environments. In addition, numerous plugins contributed by a vibrant community expand its functions, enabling it to have a broader range of applications than traditional wikis.This product is installed and deployed through Kunpeng server + EulerOS 2.0.

The project's open-source image product, [**DokuWiki Engine Application**](https://marketplace.huaweicloud.com/intl/hidden/contents/d80baca7-afe6-4d10-8388-af5416f1cc56), comes pre-installed with 2025-05-14 version of DokuWiki and its runtime environment. It includes deployment templates for an easy "out-of-the-box" experience!


### System Requirements

- **RAM**: 4GB or more
- **Disk**: At least 40GB
